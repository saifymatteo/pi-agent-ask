# pi-agent-ask — moved

This repository is archived. `@saifymatteo/pi-agent-ask` now lives in
[saifymatteo/pi-extensions](https://github.com/saifymatteo/pi-extensions/tree/main/packages/pi-agent-ask),
and releases from 1.2.2 onward publish from there. The npm package name is unchanged:

```bash
pi install npm:@saifymatteo/pi-agent-ask
```

File issues at [saifymatteo/pi-extensions](https://github.com/saifymatteo/pi-extensions/issues).

changes are AGPL-3.0-only; the upstream MIT notice still covers the upstream code.
